## HKUST Course Tree link

The filetree sidebar/navbar renders a link to the separately deployed,
browser-only [HKUST Course Tree](https://github.com/Thearthman/HKUSTECH-Tree)
visualizer. Set `TECHTREE_URL` in `.env` (or the Vercel project settings) to the
deployed URL; the default is `https://hkustech-tree.vercel.app`.
