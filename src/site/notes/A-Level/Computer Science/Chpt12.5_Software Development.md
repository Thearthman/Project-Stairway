# Stages in program development
1. Analysis
	1. The first step, Investigate the *Issues* and *Current* situation(maybe of the already developed system). A **Requirement Specification** is drawn up. 
	2. Next, plan a solution. *decide* **which** **Solution** to settle on 
	3. Decide on how to solve the problem. There are two ways:
		1. Bottom-up: Which *starts* with **small sub-problems**.
		2. Top-down: Stepwise refining using pseudocode, flowcharts or structure charts.

# Testing
## Normal Test
Test with typical data that are valid.

## Abnormal Test
Test invalid data that the system should not accept

## Boundary Test
Test what happen when getting close to the boundary




# Maintenance

## Adaptice Maintenance
When there is a problem to correct

## Perfective
To make things work better, for performance improvements

## Adaptive
To adapt to new needs, maybe new technology, requirements, environment.
